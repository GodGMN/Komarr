# v0.1.0-alpha.1 release notes (draft)

This draft records the first manga-focused Komarr alpha. The release tag and final end-to-end matrix remain in Runewire task #38.

## Available now

- AniList manga lookup and saved collections with volume or chapter tracking.
- Manga-specific release parsing, aliases, quality decisions, interactive search, and manual review. Ambiguous matches do not trigger automatic grabs.
- Torznab/Newznab indexer search and RSS through the existing *arr integrations, plus qBittorrent, Transmission, SABnzbd, and NZBGet clients.
- Completed-download inspection, seeding-safe hardlink or copy imports, item coverage, history, and blocklist.
- Wanted coverage, bounded library scan, and explicit in-place mapping of existing archives.
- First-run health checks, database/config backup restore, and Docker builds for Linux amd64 and arm64.

## Current limits

- Prowlarr uses its **Readarr** application type and Books category until native Komarr support is added upstream. See the [tested compatibility flow](../integrations/prowlarr-nyaa.md).
- Some inherited settings screens and background book services remain. Manga acquisition uses the dedicated manga routes and domain records.
- AniList is needed for new-title lookup, but saved manga and local collection management work when it is unavailable.
- The image is an early alpha. Back up `/config` before upgrades and review automatic acquisition decisions and imported file coverage.

## Verification before tagging

- [ ] Parser/domain and metadata/indexer/client tests pass.
- [ ] Docker and browser smoke checks pass on the final commit.
- [ ] A real setup → add → Prowlarr search → qBittorrent grab → CBZ import → owned coverage → later RSS release flow passes.
- [ ] Published amd64 and arm64 manifests can be pulled anonymously.
