# v0.1.0-alpha.1 release notes

This is the first manga-focused Komarr alpha. Run it from the public `ghcr.io/godgmn/komarr:v0.1.0-alpha.1` image using the [first-run guide](../getting-started.md). Keep a private backup of `/config` before upgrading.

## Available now

- AniList manga lookup and saved collections with volume or chapter tracking.
- Manga-specific release parsing, aliases, per-title quality policies, interactive search, and manual review. Ambiguous matches do not trigger automatic grabs.
- Torznab/Newznab indexer search and RSS through the existing *arr integrations, plus qBittorrent, Transmission, SABnzbd, and NZBGet clients.
- Completed-download inspection, seeding-safe hardlink or copy imports, item coverage, history, and blocklist.
- Wanted coverage, bounded library scan, and explicit in-place mapping of existing archives.
- First-run health checks, database/config backup restore, and Docker images for Linux amd64 and arm64.

## Current limits

- Prowlarr uses its **Readarr** application type and Books category until native Komarr support is added upstream. See the [tested compatibility flow](../integrations/prowlarr-nyaa.md).
- Some inherited settings screens and background book services remain. Manga acquisition uses the dedicated manga routes and domain records.
- AniList is needed for new-title lookup, but saved manga and local collection management work when it is unavailable.
- The image is an early alpha. Review automatic acquisition decisions and imported file coverage.

## Verification

- CI builds the .NET solution and frontend, checks the parser fixture corpus, and runs manga parser, matching, policy, metadata, indexer, qBittorrent, grab, import, and persistence tests.
- The Docker and Playwright smoke checks cover startup, manga screens, policy save/reload, release decisions, settings persistence, authentication, and API key access.
- A live read-only test with Prowlarr 2.6.5.5623 synced Nyaa and searched BLAME! through Komarr. The 15 observed releases were reviewed and none were auto-grabbed.
- `python3 scripts/alpha-e2e.py --image komarr:local` runs fresh Komarr, Prowlarr 2.6.5.5623, and qBittorrent 5.2.3 containers with generated CBZ files. It checks Prowlarr sync, AniList add, interactive grab, completed-file import, owned volume coverage, source preservation, and an automatic later volume from RSS. The fixture preloads its tiny archives into qBittorrent and marks them complete; swarm transfer is outside this test.
- Anonymous pulls of both `linux/amd64` and `linux/arm64` image variants passed. The arm64 image was pulled and its manifest checked; runtime execution was tested on amd64.

The [populated alpha upgrade check](../testing-upgrades.md) runs in CI for later
changes. It verifies the tagged alpha database against a candidate image and
restores a real backup into a fresh container.
